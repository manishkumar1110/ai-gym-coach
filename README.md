# AI Gym Coach 💪

AI Gym Coach is an AI-powered fitness application that helps users track workouts and analyze exercise movements using computer vision. It provides an interactive interface for exercise tracking and workout guidance.

## ✨ Features

* **Exercise Detection:** Analyze body movements during workouts.
* **Workout Tracking:** Track repetitions and exercise progress.
* **Exercise Guidance:** Support for squats, push-ups, biceps curls, shoulder presses, and lunges.
* **AI Coaching:** Generate workout feedback.
* **Progress Tracking:** Review workout history and performance.
* **Interactive Interface:** Built with Streamlit for an accessible user experience.

## 🛠️ Tech Stack

* Python
* Streamlit
* OpenCV
* MediaPipe
* Pandas
* Computer Vision
* Groq API
* gTTS (Text-to-Speech)
